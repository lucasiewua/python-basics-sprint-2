# 📊 Projeto Final - Estruturas de Dados e Análise com Python (Sprint 2)

### 📝 Sobre o Projeto
Este repositório armazena o projeto prático final desenvolvido durante o **Sprint 2** do curso de **Ciência da Computação na TripleTen**. O foco principal deste desafio foi avançar no uso do Python para manipulação, filtragem e organização de volumes de dados, simulando cenários reais de análise de negócios.

### 🛠️ Conceitos e Recursos Utilizados
- **Estruturas de Dados Avançadas:** Trabalho com listas complexas, dicionários (`dicts`) e tuplas para mapeamento de informações.
- **Tratamento de Dados:** Identificação de valores ausentes, limpeza de dados duplicados e padronização de tipos de variáveis.
- **Lógica e Filtros Avançados:** Criação de funções com múltiplos critérios para extrair insights específicos dos dados.
- **Versionamento Estruturado:** Uso de Git e GitHub para documentação e controle de progresso do código.

### 🎯 Resultados e Aprendizados
- Capacidade de transformar dados brutos em informações organizadas para tomada de decisão.
- Desenvolvimento de algoritmos mais eficientes e performáticos para processamento de dados.
- Alinhamento de lógica técnica com visão analítica de negócios (análise de métricas e comportamentos).
